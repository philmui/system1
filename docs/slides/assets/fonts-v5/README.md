# Version 05 typography

Salesforce Sans regular and bold were converted to WOFF2 from the installed Salesforce fonts identified by this manifest. The user-provided Salesforce reference deck uses this family for body text. Font metadata retains its original preview-and-print embedding setting (`fsType=4`); conversion does not change those rights. These assets support faithful display and portable export of the requested presentation.

Headings use the already bundled Manrope 700. The reference heading font, Avant Garde Demi SFDC, is only present as compressed EOT/MTX data in the supplied PPTX; no valid standalone OpenType font was available for this build. This substitution is deliberate and is documented in the style study. Earlier font assets remain unchanged.
